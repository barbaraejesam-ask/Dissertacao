# Mapa de Indicadores de Saneamento - Santa Catarina

Mapa interativo com a distribuição espacial de indicadores de saneamento dos municípios de Santa Catarina, considerando a regulação por exposição (ProSun).

**Acesse o mapa:** https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

## Sobre

- Abrangência: municípios de Santa Catarina
- Séries históricas: SNIS (2003-2022) e SINISA (2023-2024)
- Seleção de indicador e de múltiplos anos
- Atalhos para anos dos marcos legais (2007, 2020 e 2024) e para o último ano disponível

## Como usar

Abra o link acima em qualquer navegador. Escolha o indicador, selecione os anos de interesse e explore o mapa. Não é necessário instalar nada.

- SINISA - Sistema Nacional de Informações em Saneamento Básico (2023-2024)
